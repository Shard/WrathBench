# wrathbench.shard.page — the public dashboard.
#
# Permissive on purpose. The site is a static projection of the run record — the
# content boundary in docs/PUBLIC-DASHBOARD.md is what decides what a stranger
# may read, not a crawler directive, and a directive is not an access control in
# any case. What a served robots.txt buys is the social card: Slack and Twitter
# honour it, so a link pasted anywhere unfurls with the title, the sentence and
# the ship-time Pareto picture.
#
# It covers this hostname only, and that is all it needs to: everything a
# crawler would find on the data hostname (`wrathbench-data.shard.page`) is the
# published JSON and the minimap tiles, both of which the site itself renders.

User-agent: *
Allow: /
