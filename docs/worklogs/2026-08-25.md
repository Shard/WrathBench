# 2026-08-25

## Run feed: composite rows — turn headers, merged tool-call cards, latency figures

The run page's feed rendered every trajectory entry as its own card, which for
one turn with one snippet meant eight cards, three of them showing the same
code (a `tool_call` whose args are the code, the `snippet`, and the headers
around them). Reworked into a composite view derived in
`dashboard/src/lib/feedgroup.ts`, pure over the entry window:

- **Turn header** — one head-only row per `request`, with the
  `events_served (via:"context")` batch that was packed into it folded in:
  `turn N · msgs · chars · events · opcodes`, raw links for both entries.
- **Tool-call card** — `tool_call` → `snippet` → `snippet_result`/`tool_result`
  as one card: input on top (the snippet's code, or the call's args for other
  tools), result under a dashed rule, error styling from the result, per-part
  raw links. The redundant `tool_call` row for snippets is gone.
- **Latency** — `response` rows show time since the last thing that fed the
  model; call cards show `result.ts − call.ts`. The duration is withheld when
  the writer appended the record after the fact (the claude driver's triple,
  keyed on its `call` index; the MCP server's turn-less pairs), because that
  spread is write time, not run time — only `runner/src/loop.ts` records the
  call before dispatching it.

Pairing is by adjacency with agreement checks on turn/call/name, never a
stateful id join, because nothing else survives this feed's edges: the window
loads the last 200 and prepends on "load earlier", and a live tail delivers a
call before its result. Orphan halves render alone and heal when the partner
arrives (`groupFeed` re-derives per change). The fixed loop's mid-call
interleavings — `state` ticks and `events_served (via:"tool")` — are scanned
past (bounded) and emitted ahead of the card; any other entry type between a
call and a result means the result was never written.

Tests in `dashboard/test/feedgroup.test.ts` pin all three writers' shapes and
the window edges; `fmtLatency` (ms → s → m:ss, empty for unknown) in
`lib/format.ts` with tests. `bun test` dashboard suite green apart from 7
pre-existing map-page failures that reproduce on a clean tree in this
container (bun 1.3.11 vs the pinned 1.4.x); root `bun run typecheck` green.
