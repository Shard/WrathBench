# 2026-08-25

## Model logos across the dashboard; model-lineup.json is the identity catalog (ADR-0045)

Branch `claude/model-logos-ui-display-7edx3g`, PR #18.

The dashboard now shows a model's logo wherever a model is named: prepended to
the roster-name titles on the models page, in the fleet page's model cells
(`FleetRow` grew a `modelList`, de-duplicated by family, alongside the joined
label) and paused list, in a new icon column between the results chart's label
gutter and its bars, in the results/ladder tables and the run-detail model row,
and on the map — where a recognized model's pip becomes a light icon puck, with
the old run-colored dot kept as the fallback for unknown models and undecoded
images (trails and sidebar swatches stay run-colored: run identity ≠ model
identity).

Identity is data, not code. `infra/model-lineup.json` (ADR-0045) defines
families `{ id, name, vendor, icon, match }`; matching is lowercase +
strip `:free` + first glob wins, in file order. `dashboard/src/lib/lineup.ts`
is the whole of the code that reads it (14 tests), `ModelIcon` inlines the SVG
text so mono `currentColor` icons follow the theme, and an unmatched id gets a
neutral monogram — no per-model branch anywhere. fleet.json stays a pure
scheduling catalog.

Logos are fetched, not curated: `bun run model-logos`
(`infra/fetch-model-logos.ts`) pulls the pinned `@lobehub/icons-static-svg`
tarball from registry.npmjs.org (sha512-verified against `dist.integrity` —
CDN hosts are proxy-blocked in the web sandbox, the registry is not), extracts
exactly the icons the lineup names into
`dashboard/src/assets/model-logos/<family-id>.svg` (committed; the packaged
`<title>` is stripped so the badge's own tooltip wins), prunes orphans, and is
idempotent; `--check` catches lineup/asset drift offline. Pure helpers (lineup
validation, a ~40-line ustar reader, asset planning) are fixture-tested with no
network (18 tests). Provenance in THIRD-PARTY-NOTICES.md.

Commits: a811986 (lineup + ADR), 7c93ee5 (CLI + assets), 6e10e98 (dashboard
wiring), 6248515 (title strip).
