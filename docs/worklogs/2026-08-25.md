# 2026-08-25

The ADR series is consolidated. Forty-four numbered records had accumulated in
four days — unreadable as a set, unholdable by an agent, and cited from 600+
places including user-facing strings. They are now one document,
`docs/METHODOLOGY.md`, organized by principle rather than by accretion, and
`docs/decisions/` is deleted (full texts remain in git history).

## The consolidation

- **`docs/METHODOLOGY.md`** states the guiding principles (server truth, client
  parity, model-as-only-variable, signals-not-scores, stamped-never-recomputed,
  earned surface, explain-don't-play, values-not-exceptions) and the
  methodological decisions that shape what a result means, grouped: what is
  measured, client fidelity, the model surface, context policy, episodes/lanes/
  evidence, scoring, the reference bundle. The table mapping every former ADR
  number to where its decision now lives sits in `docs/WORKLOG.md`, beside
  the day files that cite the numbers.
- **Operational "why" folded into the owning docs**: fleet service, preflight
  gate, stop-pauses, deploy window and the scheduling policy into
  `docs/OPERATIONS.md`; parked socket, mover, map view, dashboard split, stock
  core and the staged run-data-storage plan (the former storage proposal, still
  proposed) into `docs/ARCHITECTURE.md`; provider cache weather was already in
  `docs/COSTS.md`; bundle build rules stay in `wiki/README.md`.
- **Superseded records** (0008, 0014, 0024, 0026, 0028, 0030, 0031, 0032, and
  the superseded halves of 0034/0043) are simply gone — their surviving content
  was already restated by their successors, which are what METHODOLOGY absorbed.
- **The decision process changed with the format**: METHODOLOGY is edited in
  place — fold a new decision into its section, prune what it obsoletes, git
  history holds the past. CLAUDE.md and WORKLOG.md now say so; no new
  append-only record series.

## Reference cleanup

Every `ADR-XXXX` citation outside `docs/worklogs/` is gone (~660 across docs,
code comments, test names, and — the real offenders — user-facing surfaces:
fleet CLI errors and `--help`, deploy-script errors, dashboard prose and
tooltips, `fleet.json` `_notes`, wiki build `help:` strings, the generated
`sdk/API.md`). Comments now state the rule or point at the owning doc; test
names name the rule they test. Model-facing bytes (system prompt, MCP tool
descriptions) never carried ADR text and are untouched. The one nuance:
`sdk/API.md` is snippet-readable in the sandbox and carried two ADR citations;
removing them is a surface-text change — uniform across models, inside the
0.x free-change window, noted here rather than hidden. Worklogs keep their
historical citations, which resolve through the table in `docs/WORKLOG.md`.

Also fixed in passing: a merge-garbled Objective/Prompt block in
`docs/EPISODES.md` (`e90`), and `docs/OPERATIONS.md`'s scheduling-policy
section still describing the retired `policy.extras` race/class cycle — it now
matches the 0.5 tier/idle shape.
